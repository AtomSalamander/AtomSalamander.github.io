# 🔵 Статус-эффекты для Owlbear Rodeo

Расширение рядом с трекером инициативы. Лежит в папке `status/` того же репозитория.
Вместо рамок, которые перекрывают друг друга, эффекты показываются небольшими цветными кругляшками
в ряд под токеном (если их много — в несколько рядов).

## Установка
1. Залей папку `status/` в корень репозитория `AtomSalamander.github.io` (рядом с `fx/`, `legendary/`).
2. В Owlbear: Профиль → Extensions → Add Extension → `https://atomsalamander.github.io/status/manifest.json`.
3. Включи расширение в комнате. У игроков оно подхватится само через комнату.

Независимо от остальных расширений — их включать не обязательно.

## Как пользоваться (мастер)
- Выдели один или несколько токенов → открой панель «Статус-эффекты» → нажимай на эффекты в библиотеке.
  Повторный клик снимает эффект.
- «＋ Свой эффект»: название, значок (1–2 символа или эмодзи), счётчик, цвет и описание.
  - «Повесить на выделенные» — сразу на токены.
  - «★ В библиотеку» — сохранить в «Мои сохранённые».
- ✎ у своего эффекта — изменить, × — удалить. ✎ у встроенного — скопировать в форму и сделать свою версию.
- В блоке «Выделено» клик по эффекту открывает его редактирование прямо на токене. −/+ меняют счётчик.
- Библиотека хранится в браузере мастера и доступна во всех комнатах. Чтобы перенести её на другой
  компьютер, используй «Настройки → Резервная копия» (выгрузить → скопировать → вставить → загрузить).
- Размер кругляшков S / M / L — в «Настройках», общий для всех в комнате.
- Правый клик по токену → «Статус-эффекты» — маленькое окошко, в котором можно читать, править,
  снимать, сохранять (★) и добавлять эффекты из библиотеки.

## Как пользоваться (игроки)
- Нажми на кругляшок под токеном, и откроется окошко со всеми эффектами этого токена.
  Эффект, по которому нажали, уже раскрыт. Нажми на другой эффект, чтобы раскрыть его.
- То же окошко открывается через правый клик по токену → «Статус-эффекты». Ещё можно выделить токен
  и открыть панель расширения.
- Игроки только читают. Вешает и снимает эффекты мастер. На скрытых токенах игроки кругляшки не видят.

## Встроенная библиотека (`conditions.js`)
- **Состояния D&D 5e:** ослеплён, очарован, оглох, истощение (счётчик = уровень), испуган, схвачен,
  недееспособен, невидим, парализован, окаменел, отравлен, сбит с ног, опутан, ошеломлён, без сознания.
- **Частые эффекты:** концентрация, ярость, ускорен, благословлён, порча, метка.

Чтобы добавить эффект для всех своих комнат в коде, допиши его в `conditions.js`:
```js
{ key: "burning", name: "Горит", icon: "🔥", color: "#f97316", n: 3, desc: "1к6 урона огнём в начале хода…" }
```

## Как это устроено
- Эффекты токена хранятся в его метаданных (`status-fx/list`) и переезжают вместе с токеном
  (копирование, сохранение сцены).
- Кругляшки — локальные объекты. Их рисует фон расширения у каждого игрока, и они прикреплены к токену.
  Они не попадают в сцену и в историю Ctrl+Z.
