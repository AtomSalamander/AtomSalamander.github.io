# Музыка — расширение для Owlbear Rodeo

Мастер вписывает название трека и нажимает «Включить» — у всех игроков появляется плашка «сейчас звучит». Никаких внешних программ не нужно.

## Установка

1. Залей папку `music/` в репозиторий и дождись обновления GitHub Pages.
2. В Owlbear Rodeo: **Profile → Extensions → Add Extension** → вставь  
   `https://atomsalamander.github.io/music/manifest.json`
3. Включи расширение в комнате.

## Как пользоваться (мастер)

- Нажми на иконку ноты → впиши название (и, если хочешь, подпись: альбом, место, сцена) → **▶ Включить** или Enter.
- **⏸ Пауза / ▶ Продолжить** — плашка остаётся, эквалайзер замирает.
- **■ Убрать у всех** — плашка исчезает.
- **Недавние** — последние 12 треков: клик включает снова, ✕ убирает из списка (список хранится в браузере мастера).
- **Крупно держится** — 4/6/10 с, сколько новая плашка остаётся крупной.

## Как ведёт себя плашка

- При новом треке плашка **крупная**, потом **уменьшается** в узкую строку у правого нижнего угла.
- **✥** — переместить (Esc / правый клик — отмена), **×** — скрыть до следующего трека, «Показать снова» в панели вернёт её.
- Клик по маленькой плашке ненадолго её увеличивает.
- Место и «скрыто» запоминаются у каждого игрока отдельно.
