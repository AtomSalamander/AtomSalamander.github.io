# Музыка (Kenku FM) — расширение для Owlbear Rodeo

Когда мастер включает трек в **Kenku FM**, у всех игроков в Owlbear Rodeo появляется плашка с названием трека.

## Установка

1. Залей папку `music/` в репозиторий (рядом с `legendary/`, `fx/` и т.д.) и дождись обновления GitHub Pages.
2. В Owlbear Rodeo: **Profile → Extensions → Add Extension** → вставь  
   `https://atomsalamander.github.io/music/manifest.json`
3. Включи расширение в комнате.

## Настройка Kenku FM (только мастер)

1. В Kenku FM: **Settings → Remote** → включить. Адрес `127.0.0.1`, порт `3333`.
2. В Owlbear нажми на иконку ноты → в панели должно стать «Kenku FM подключён».
3. Играй музыку из **плейлистов** Kenku — плашка появится у всех.

Kenku FM и вкладка Owlbear мастера должны быть **на одном компьютере**, и вкладка Owlbear должна быть открыта: именно она спрашивает Kenku о треке раз в 2 секунды и передаёт название игрокам.

## Как ведёт себя плашка

- При новом треке плашка **крупная и заметная** (4/6/10 с — выбирается в панели), потом **уменьшается** в узкую строку.
- По умолчанию стоит **чуть выше правого нижнего угла**.
- **✥** — переместить: экран затемнится, кликни туда, куда поставить плашку (Esc / правый клик — отмена).
- **×** — закрыть. Плашка не появится до следующего трека. «Показать снова» в панели вернёт её.
- Клик по маленькой плашке ненадолго её увеличивает.
- Место и «закрыто» запоминаются у каждого игрока отдельно. «Вернуть в угол» сбрасывает место.

## Если пишет «Нет связи с Kenku»

1. Проверь, что Kenku FM запущен и Remote включён, адрес в панели совпадает.
2. Браузер может блокировать доступ сайта к `127.0.0.1`. Если Chrome спросит разрешение на доступ к локальной сети — разреши. Можно попробовать Firefox.
3. Запасной вариант — мост: установи Node.js, скачай `kenku-bridge.mjs`, запусти `node kenku-bridge.mjs` и укажи в панели адрес `http://127.0.0.1:3334`.
4. На крайний случай есть **ручной режим**: вписать название в панели и нажать «Показать».

## Файлы

| Файл | Назначение |
|---|---|
| `manifest.json` | описание расширения |
| `background.html/.js` | фоновая логика: опрос Kenku (у мастера), показ плашки у всех |
| `plate.html` | сама плашка |
| `move.html` | экран выбора места |
| `panel.html/.js` | панель по кнопке в Owlbear |
| `kenku.js`, `const.js` | работа с Kenku Remote, общие настройки |
| `kenku-bridge.mjs` | необязательный мост на случай блокировки браузером |
