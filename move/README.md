# 🏃 Передвижение (DnD) для Owlbear Rodeo

Третье расширение рядом с трекером инициативы и эффектами. Лежит в папке `move/` того же репозитория.
Считает передвижение в бою как в Foundry VTT: тащишь токен, за ним рисуется путь по клеткам и видно, сколько осталось.

## Установка
1. Залей папку `move/` в корень репозитория `AtomSalamander.github.io` (рядом с `fx/` и `tracker.html`).
2. В Owlbear: Профиль → Extensions → Add Extension → `https://atomsalamander.github.io/move/manifest.json`.
3. Включи расширение в комнате. У игроков оно подхватится само.

Трекер инициативы (старое расширение) должен быть включён: «чей ход» берётся из него
(метаданные комнаты `com.dnd-tracker/initiative`). Имя токена должно совпадать с именем в трекере,
цифры в конце не важны: «Гоблин 2» = «Гоблин».

## Игрокам
- **Свой токен.** Выдели токен → в панели «🏃 Передвижение» нажми «← выделение» (или правый клик по токену → «🏃 Мой токен»).
  Если у игрока на сцене ровно один его токен, он привяжется сам. На другой сцене токен найдётся по имени.
- **Скорость** (по умолчанию 30 фт), **доп. скорость на этот ход** (сбрасывается в начале следующего хода),
  **×2 Ускорение** (держится, пока не снимешь галочку), **💨 Рывок** (ещё столько же движения; до 3 раз; сбрасывается в начале хода).
- **🌿 Труднопроходимая местность** — пока галочка стоит, каждые 5 фт стоят 10 фт.
- **↶ Отменить шаг** — токен возвращается в начало последнего перемещения, расстояние возвращается (в инструменте ещё и Ctrl+Z).
  **⟲ Сбросить ход** — обнулить пройденное, токен остаётся на месте.

## Как двигаться
- Возьми инструмент **🏃 Передвижение** на панели инструментов слева и тащи свой токен.
  Путь строится по клеткам за курсором (вернёшься назад — петля срежется):
  **зелёный** — хватает скорости, **жёлтый** — дойдёшь только с рывком, **красный** — не дойти.
  У конца пути: сколько стоит этот шаг, сколько останется, «💨 нужен рывок» или «✋ не хватает N фт». **Esc** — отмена.
- Обычное перетаскивание тоже считается — по прямой от прошлой позиции.
- Пройденное считается **только в свой ход**. В начале своего хода (по трекеру) всё обнуляется.
- Под токеном, чей сейчас ход, все видят «🏃 15 / 30 фт» и пунктир пройденного пути. На иконке расширения — сколько осталось.

## Диагонали
Берутся из настроек сетки сцены Owlbear: Chebyshev — диагональ 5 фт, Alternating — 5-10-5 (чётность сохраняется на весь ход),
Euclidean и Manhattan — как в Owlbear. Масштаб клетки (5 фт, 1,5 м…) тоже из настроек сетки. На шестиугольной сетке — по прямой.

## Мастеру
- В панели — список всех привязанных токенов: пройдено/максимум, ▶ у того, чей ход, кнопки ✎ (настроить токен,
  например скорость монстра), ↶ и ⟲.
- **🚫 Жёсткий лимит** — токен нельзя увести дальше, чем позволяет скорость (с рывком). По умолчанию выключено.
- Если у игрока нет прав менять токен, изменения записывает фон мастера (мастер должен быть в комнате).

## Где хранится
- Метаданные токена `com.dnd-move/m`: `sp` скорость, `ex` доп. скорость на ход, `x2`, `dash`, `used` пройдено,
  `key` ключ хода, `tr` перемещения хода (для отмены и пунктира), `pos` последняя учтённая позиция, `dg` диагонали за ход.
- Метаданные комнаты `com.dnd-move/cfg`: `{ hard }`.
- localStorage игрока: `dndmove_tok` (свой токен), `dndmove_diff` (трудная местность).
