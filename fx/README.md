# ✨ Эффекты (DnD FX) для Owlbear Rodeo

Второе расширение рядом с трекером инициативы. Лежит в папке `fx/` того же репозитория.

## Установка
1. Залей папку `fx/` в корень репозитория `AtomSalamander.github.io` (рядом с `tracker.html`).
2. В Owlbear: Профиль → Extensions → Add Extension → `https://atomsalamander.github.io/fx/manifest.json`.
3. Включи расширение в комнате. Его нужно поставить только мастеру — у игроков оно подхватится само через комнату.

Старое расширение (трекер + рулетка) остаётся как было и должно быть включено: именно его фоновая часть
принимает данные из вкладки трекера и кладёт их в комнату, а мод эффектов их читает.

## Как пользоваться
- Выдели токен заклинателя → «🪄 Кто ← выделение». Выдели цели (Shift) → «🎯 Цели ← выделение».
- Выбери способность (двойной клик — сразу применить). Для способностей с ⏳ выбери длительность и чей ход.
- «📌 Сбоку» — закрепить панель, чтобы она не закрывалась при кликах по карте.
- Эффекты снимаются автоматически, когда в трекере наступает нужный ход. Откат хода назад эффекты не трогает.
- Чей ход определяется по имени: имя токена должно совпадать с именем в трекере (цифры в конце игнорируются:
  «Гоблин 2» = «Гоблин»). Если не совпало — эффект висит, пока не снимешь вручную, или выбери имя из списка.

## Формат способности (`abilities.js`)
```js
{
  id: "curse", name: "Проклятие", icon: "🕯️", group: "Жрица", desc: "…",
  cast: [                       // анимация применения, шаги по порядку
    { fx: "beam", color: "#9b4dff", core: "#fff", width: 0.1, duration: 700 },
    { fx: "burst", at: "targets", after: "hit", color: "#9b4dff", radius: 0.7 },
  ],
  aura: [ { fx: "ring", color: "#a24bff", dash: true, spin: 40 } ],  // висящий эффект
  auraOn: "targets",            // или "caster"
  until: { who: "caster", when: "e", n: 1 },   // s=начало, e=конец, x=вручную; n=какой по счёту ход
}
```
Размеры — в клетках сетки, время — в мс, скорость — клеток/сек.

**Шаги cast:** `projectile` (снаряд: size, speed, trail, arc), `beam` (луч: width, duration, hitAt),
`burst` (вспышка+искры: radius, sparks), `area` (область: radius, opacity, edge), `rise` (частицы вверх: count, height),
`image` (картинка/GIF/WebM: url, size, duration),
`letters` (буквы имени цели вырываются, складываются в слово и улетают к заклинателю: text, size, speed, ghosts, color, stroke, glow; буквы рисуются векторно из `glyphs.js` — русский и латинский алфавит, цифры),
`implode` (кольцо и искры стягиваются в точку: radius, sparks, duration).
`smoke` (клубы дыма: radius, count, size, rise, opacity, color2), `debris` (разлетающиеся обломки: radius, count, size, hot),
`shock` (ударные кольца: radius, rings, width), `embers` (тлеющие угольки вверх: count, height, spread, color2),
`bolt` (молния: width, jag, segments, flick, grow; `wave: true` — извивающееся щупальце, freq; `from: "sky"` — бьёт с неба, height),
`sigil` (рунический круг под целью: radius, points, runes, rune, spin, fill).
Доп. опции: у `projectile` — `embers` (искры за снарядом), у `burst` — `stars: true` (звёздочки вместо искр),
у `rise` — `glyph: "+"`, `glyphEvery`, `glyphSize`, `glyphColor` (символы среди частиц).
Общие поля: `at` (`targets` | `caster` | `center`), `after: "hit"` | `"return"`, `delay`, `stagger`, `color`, `core`.
У `projectile` есть `reverse: true` — снаряд летит от цели к заклинателю; `after: "return"` — шаг в момент, когда он долетел.

**Спасброски:** `save: "Мдр СЛ 14"` даёт в панели две кнопки — «Провал» (обычная анимация + аура) и «Спасбросок пройден»
(анимация `castSave`, без ауры).

**Ауры:** `ring` (кольцо: size, width, dash, spin, pulse), `glow` (свечение под токеном), `orbit` (огоньки по кругу:
count, radius, size, speed), `image` (картинка/GIF на токене: url, size, spin),
`dome` (сияющий купол/барьер с сотами: size, cells, grid, highlight, fill, sweep, rippleEvery),
`sigil` (вращающийся рунический круг под токеном: size, runes, rune, spin, fill), `stars` (звёздочки над головой: count, size, speed, color2),
`wisps` (клубящаяся тьма/дымка вокруг: count, size, radius, speed, color2). У всех аур есть `flicker` (0–1) — мерцание.

`auraDelay: 650` (поле способности) — задержка появления ауры после попадания, в мс (например, купол возникает, когда искры собрались).

## v1.2.0

### Доступ для игроков
У мастера рядом с каждой способностью есть галочка **👥**. Отмеченные способности появляются у игроков в той же панели «✨ Эффекты»: игрок выделяет токены, выбирает способность и применяет её. Висящие эффекты от игроков записывает фон мастера (мастер должен быть в комнате). Снимать эффекты может только мастер. Список разрешённых хранится в метаданных комнаты (`com.dnd-fx/allow`), фон проверяет его и для анимаций, и для аур.

### Атаки: попадание / промах
Поле `attack: true` меняет кнопки на «🎯 Попадание» (`cast`) и «💨 Промах» (`castSave`).

### Новые опции снаряда (`fx: "projectile"`)
- `shape: "arrow" | "spear"` — фигурный снаряд, повёрнутый по направлению полёта; `length` — длина в клетках.
- `stick: мс` — снаряд «втыкается» и остаётся на месте столько миллисекунд (с лёгкой дрожью).
- `ribbons: [цвета]` — спиральные цветные ленты за снарядом (`ribbonLen`, `ribbonAmp`, `ribbonSize`).
- `glow`, `glowColors: [цвета]` — ореол и переливание его цвета.
- `miss: true` — снаряд пролетает мимо цели (`overshoot`, `side` в клетках); шаги с `at: "miss"` играют в точке падения.
- Молния `from: "sky"` теперь понимает `after: "hit"`.


## Часы и гипноз
- Шаг `watch` — иллюзорные карманные часы на цепочке рядом с целью качаются как маятник (size, length, swing, period, side, color, edge, face, hands, glow, hitAt, duration; `glitch: true` — иллюзия рвётся и гаснет). Его `hitAt` считается моментом попадания, так что следующие шаги с `after: "hit"` и аура ждут его.
- Шаг `spiral` — двойная гипнотическая спираль вращается вокруг цели и стягивается в неё (radius, turns, spin, width, color, color2).
- Аура `hypno` — спираль под токеном, сходящиеся кольца и тикающие часы над головой (size, turns, spin, width, color, color2, clock: false — без часов, clockColor, clockSize, height).

## v1.3.0

### Новые эффекты
- **💥 Чародейский выброс** — заговор-атака (Попадание / Промах), 7 стихий: огонь, холод, кислота, электричество, яд, звук, психическая.
- **🐉 Дыхание дракона** — конус 15 фт, 5 стихий. **🐲 Дыхание дракона — наделение** — аура на того, кого коснулись; стихия запоминается и подставляется в «Дыхание дракона».
- Стихия выбирается в панели (строка «стихия»), запоминается для каждой способности.

### Заклинания по области (как в BG3)
- Выбери только **«Кто»**, нажми **«🎯 Прицелиться»** — над картой появится превью (сфера с кругом дальности или конус), токены внутри подсвечиваются красным.
- **Клик** — применить, **Esc** — отмена. Цели определяются сами по области.
- Работает для «Огненного шара» и «Дыхания дракона». Если в настройках сетки 1 клетка ≠ 5 фт, область пересчитается по масштабу.

### Горячие клавиши
- **Alt+1** — выделенный токен становится «Кто» (над ним всплывает «ЗАКЛИНАТЕЛЬ»).
- **Alt+2** — выделенные токены становятся «Целями» (над ними всплывает «ЦЕЛЬ»).
- То же есть в меню правого клика по токену. Клавиши меняются в начале `background.js` (`KEY_CASTER`, `KEY_TARGETS`).

### Для своих способностей (`abilities.js`)
- `area: {shape:"sphere", radius, range}` или `{shape:"cone", length, angle}` — в футах.
- `elements: ["fire", …]` + цвета `"$c1" "$c2" "$c3" "$d"` в шагах; `el:` — шаг только для стихии; `per:{lightning:{…}}` — доп. опции.
- Шаг `to:"point"` (снаряд/луч/молния летит в точку области), `at:"point"` — эффект в точке области, новый эффект `fx:"cone"` (`length`, `angle`, `count`, `size`, `bolts`).
