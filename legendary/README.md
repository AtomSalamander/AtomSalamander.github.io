# Легендарные действия — расширение для Owlbear Rodeo

По кнопке у всех игроков в комнате появляется надпись по центру экрана:

> **«Имя босса»** использует легендарное действие **«Название способности»**

Остальные папки (`/fx`, `/emergence` и корень) не изменялись.

**Установка:** Owlbear Rodeo → Extensions → Add Custom Extension → `https://atomsalamander.github.io/legendary/manifest.json`

## Как пользоваться (только мастер)
1. Открой панель **Легендарные действия** на верхней панели.
2. Впиши **имя босса**. Можно выделить токен босса и нажать **← токен**, чтобы взять его имя.
3. Впиши **название легендарного действия**.
4. По желанию выбери:
   - **стоимость** (1–3 действия; на надписи появятся ромбики);
   - сколько секунд надпись держится **на экране**;
   - **цвет** надписи (золото, кровь, аркана, лёд, яд, тень).
5. Нажми **👑 Показать всем** или Enter в поле действия.
   - **👁 Только мне** показывает надпись только тебе для проверки.
   - **× Убрать надпись** закрывает её у всех досрочно. Любой игрок может закрыть надпись у себя кликом по ней.

Показанные действия сохраняются в списке **Действия: <босс>**, отдельно для каждого босса. Клик по действию сразу показывает его всем, а × удаляет его из списка.

## Файлы
- `manifest.json` — описание расширения.
- `panel.html`, `panel.js` — панель мастера.
- `background.html`, `background.js` — фон у каждого игрока; получает сигнал и открывает надпись.
- `banner.html` — сама надпись с анимацией.
- `const.js` — канал, цветовые темы, длительности.
